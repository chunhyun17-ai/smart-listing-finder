# 네이버 부동산 조회 방식 확인 결과

> PLAN.md 작업 1번 "네이버 부동산 이용약관을 확인하고 매물 조회 방식을 결정한다"의 결과 기록
> 확인일: 2026-11-12 · 작성자: 탐험가 · 상태: **결정 대기** (아래 "결정할 것" 참고)

## 확인한 것

| 확인 대상 | 확인 결과 | 의미 |
|---|---|---|
| 네이버 개발자센터 오픈API 목록 ([apilist](https://developers.naver.com/docs/common/openapiguide/apilist.md)) | 목록에 "부동산"이 한 번도 나오지 않는다. (검색, 쇼핑, 데이터랩, 캡차, 지도·지역 등만 있음) | 매물을 제공하는 **공식 API는 확인되지 않았다** |
| 네이버 부동산 `robots.txt` ([land.naver.com/robots.txt](https://land.naver.com/robots.txt)) | `User-agent: *` / `Disallow: /` / `Allow: /$` — 첫 페이지 외 모든 경로의 자동 접근을 허용하지 않는다고 적혀 있다 | 프로그램이 자동으로 매물 페이지를 읽는 것을 **네이버가 원하지 않는다는 표시** |
| 네이버 서비스 이용약관 ([policy.naver.com](https://policy.naver.com/policy/service.html)) | 네이버의 사전 허락 없이 자동화된 수단(매크로, 봇, 스파이더, 스크래퍼 등)으로 사람의 실제 이용을 전제로 하는 서비스를 이용하는 것을 금지하고, 차단을 우회하는 행위(IP를 계속 바꾸거나 캡차를 우회하는 것 등)도 금지한다 | 자동 조회는 **약관 위반 가능성이 높다** |

## 확인하지 못한 것

- "네이버 부동산" 전용 약관 원문은 찾지 못했다. 공통 이용약관 기준으로만 판단했다.
- 네이버와 제휴해 매물 데이터를 받는 별도 경로가 있는지는 확인하지 못했다.
- 이 문서는 법률 자문이 아니다. 최종 판단 전에 네이버 부동산 화면 하단의 약관과 고객센터 안내를 직접 확인한다.

## 조회 방식 후보

| 후보 | 설명 | 약관·위험 | 개발 부담 |
|---|---|---|---|
| A. 샘플 데이터로 먼저 개발 | PLAN 3번의 가짜 매물로 화면·필터·의심 규칙을 모두 만든다. 실제 연계는 뒤로 미룬다 | 위험 없음 | 낮음 |
| B. 내가 직접 가져온 매물을 입력 | 네이버 부동산에서 내가 직접 본 매물 정보를 앱에 붙여넣거나 파일로 올린다. 앱은 자동으로 네이버에 접속하지 않는다 | 자동 수집이 아니라 위험이 낮다. 다만 "실시간 매물 검색"이라는 PRD must 1과는 달라진다 | 중간 |
| C. 앱이 네이버 부동산을 자동 조회 | PRD가 원래 그린 방식 | 약관·robots.txt와 충돌할 가능성이 높고, 차단·법적 분쟁 위험이 있다 | 높음 |
| D. 공식 제휴·허용 경로 문의 | 네이버에 매물 데이터 제공 방법을 문의한다 | 가장 안전하지만 시간이 걸리고 가능 여부를 모른다 | 알 수 없음 |

## 제안

**A로 먼저 시작하고, 동시에 B와 D를 알아본다.**

- A는 PLAN 3번·4번·6~12번을 막힘 없이 진행할 수 있어 개발이 멈추지 않는다.
- 실제 연계(PLAN 5번)는 B 또는 D가 가능한지 확인한 뒤에 정한다.
- C는 권하지 않는다.

## 결정할 것

위 후보 중 어떤 방식으로 갈지는 **사용자가 정한다.** 정해지면 이 문서의 상태를 "결정 완료"로 바꾸고 선택한 방식을 적는다. PRD 5번 must 1("실시간 매물 검색")의 표현을 바꿔야 하는지도 그때 함께 판단한다.
